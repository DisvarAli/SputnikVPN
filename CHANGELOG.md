# Changelog — Sputnik VPN

**Repository:** [DisvarAli/SputnikVPN](https://github.com/DisvarAli/SputnikVPN)  
**Current version:** 2.1.0 (versionCode 21)

---

## 2.1.0

### Core
- Xray VPN client for Android (VpnService + libv2ray).
- Protocols: VLESS / VMess / Trojan / Shadowsocks / Hysteria2.
- Faster TCP checks and optional Xray latency test; shorter connect timeouts.

### Mirrors
- Parallel mirror probe when GitHub/raw is unavailable.
- Yandex Translate + Bitbucket RAW for whitelist networks.
- HTML normalize for translate proxies.

### UX
- Dedicated config picker and config file import.
- Updated RU/EN help.
- Refreshed UI theme.
