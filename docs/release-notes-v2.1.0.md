## Sputnik VPN 2.1.0

### Highlights
- Config picker and config file import.
- Subscription mirror cascade when GitHub is blocked.
- Faster TCP checks and optional Xray latency test.
- Protocols: VLESS, VMess, Trojan, Shadowsocks, Hysteria2.

### Build
- **stable:** `app-stable-debug.apk` (`com.my.vpn`, `2.1.0`)
- **dev:** `app-dev-debug.apk` (`com.my.vpn.dev`, `2.1.0-dev`)
